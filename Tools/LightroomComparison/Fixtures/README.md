# Replay Lightroom edits without Lightroom

On a Mac with full Xcode (including the Metal Toolchain), a Metal device and Python 3.11+, run this from the repository root. A fresh checkout needs access to the Swift package dependencies on its first build. No Adobe software, account, Lightroom catalog, or Python packages are used for replay.

```sh
python3 Tools/LightroomComparison/A10/run.py \
  Tools/LightroomComparison/Fixtures/light-context-v1.zip .tmp/chart-before \
  --scope light --modes adaptive --paired-neutral --metrics-only
python3 Tools/LightroomComparison/A10/score.py .tmp/chart-before/report.json
```

The ZIP contains **actual Lightroom TIFF exports**, not images generated by Brightroom. Two synthetic charts (different surroundings for the same gray values) each have four captures: neutral, Highlights −50, Shadows +50 and Whites +25. Each is 1024 × 256, 16-bit ProPhoto RGB; the resolved Camera Raw version is 18.7, process version 15.4. The original developed inputs, authored XMP, resolved Adobe settings, export options and output ICC travel with the expected outputs. These eight cases check that rendering works and expose the three controls' response; they do not establish compatibility across photographs or the entire slider range.

For Color Grading use `grading-wheels-v1.zip` with `--scope all --paired-neutral`. It contains a different synthetic chart and four actual captures: neutral, the shadows wheel, the highlights wheel, and a combination using all four wheels. The CI job runs both packs. For larger packs, `--scope all` replays every registered row, retaining its calibration or validation role in the report.

## Iterate on Parametric

1. Measure the current implementation as above. Change a feature in BrightroomParametric or its Metal kernel. Repeat the same command with a **new** output directory, e.g. `.tmp/chart-after`. Use one replay at a time per checkout; it shares Xcode build products.
2. Compare the two reports on the Mac, or copy just the JSONs back to a Linux agent:

   ```sh
   python3 Tools/LightroomComparison/A10/score.py .tmp/chart-after/report.json \
     --baseline .tmp/chart-before/report.json
   ```

   Negative Δ means the candidate moved closer. Absolute p95 is the 95th percentile of the largest absolute RGB channel difference per pixel in linear Display P3 (white = 1). Response p95 compares **(Brightroom edit − Brightroom neutral) − (Lightroom edit − Lightroom neutral)**. Inspect both, keeping calibration and held-out photos separate. The scorer rejects changed inputs, XMPs, references, neutral pairing, comparator or runtime. It sets no overall pass/fail threshold for color. Omit `--metrics-only` for candidate PNGs and difference images.
3. In GitHub Actions, **Lightroom reference replay** runs the public charts on a macOS worker for relevant pull request updates. A Linux agent such as Devin can edit the checkout, push a candidate to its PR, and read the job summary or download the JSON:

   ```sh
   gh run list --branch YOUR_BRANCH --workflow lightroom-replay.yml
   gh run download RUN_ID --name light-context-report --dir result
   ```

   To run successive iterations without pushing, use the same command on a persistent Apple Silicon macOS VM with a working Metal device and Xcode. The VM does not need Lightroom or GUI interaction. GPU, OS/driver and Xcode versions can affect measurements; compare changes on matching workers. The Actions workflow checks for an actual Metal device before rendering.

## Record another reference set

On the capture Mac, [acquire and register a set in Lightroom](../A10/README.md#acquire-another-case-set), or [register a supplied before/XMP/after triplet](../A10/README.md#compare-a-supplied-bitmap--lightroom-export-pair). Then freeze that registration:

```sh
python3 Tools/LightroomComparison/A10/reference_pack.py PATH_TO_REGISTRATION light-study.zip
shasum -a 256 light-study.zip
```

Pass `--case-id ID` (repeatable) to pack part of a set; it brings along the captured same-input neutral if one exists. The packer validates registered file hashes, keeps attribution/roles and export settings, deduplicates identical files and never overwrites a pack. Transfer this ZIP privately when it contains photographs or a third-party preset. Compare the SHA-256 with the capture Mac's value. The receiver passes the ZIP directly to the same runner; no absolute paths, reimport or access to the capture Mac is needed.

Choose the scope that matches the acquisition: e.g. `--scope light --modes adaptive --paired-neutral` for single Light sliders, or `--scope partial --modes adaptive` for a supplied full A10 photo without a captured neutral. The latter measures absolute error only. A bundle records exactly the supplied TIFFs and presets; to score a new source, intermediate slider setting, combination, RAW profile or Camera Raw process version, capture another Lightroom reference. The replay evaluates post-development TIFF effects, not Adobe's RAW demosaicing.
